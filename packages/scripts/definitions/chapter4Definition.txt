CHAPTER 4: Staking Contract Audit Requirements

This chapter requires a staking system where pilots stake 10k credits when entering a sector, and the stake can be slashed if they kill another pilot in that sector.

=== REQUIRED FUNCTIONS ===

1. activate() - Called when a pilot enters the sector
   ✅ MUST: Be external/public
   ✅ MUST: Only callable by MaxExtract contract (msg.sender check)
   ✅ MUST: Set staked[tx.origin] = true (NOT msg.sender - tx.origin is the pilot)
   ✅ MUST: Take NO parameters

2. deactivate() - Called when a pilot exits the sector
   ✅ MUST: Be external/public
   ✅ MUST: Only callable by MaxExtract contract (msg.sender check)
   ✅ MUST: Set staked[tx.origin] = false (NOT msg.sender)
   ✅ MUST: Take NO parameters

3. slash(address killer) - Called by Game contract when a pilot is killed
   ✅ MUST: Be external/public
   ✅ MUST: Only callable by Game contract (msg.sender check)
   ✅ MUST: Take exactly one parameter: address killer
   ✅ MUST: Verify killer is staked (staked[killer] == true)
   ✅ MUST: Set staked[killer] = false BEFORE calling MaxExtract.slash() (prevent double-slashing and reentrancy)
   ✅ MUST: Call MaxExtract.slash(killer, sectorId) with correct sectorId

=== REQUIRED STATE VARIABLES ===

✅ mapping(address => bool) public staked - Track who is currently staked
✅ maxExtractContract address - Store MaxExtract contract address
✅ gameContract address - Store Game contract address
✅ sectorId access - Must be accessible when calling MaxExtract.slash(). Can be read from your Registry contract's sectorId() function

=== TX.ORIGIN PATTERN ===

activate() and deactivate() MUST use tx.origin, not msg.sender:
- msg.sender = MaxExtract contract (verified for authorization)
- tx.origin = actual pilot address (used to track staking status)

Example: staked[tx.origin] = true; // CORRECT
Example: staked[msg.sender] = true; // WRONG

=== PASS CONDITIONS ===

✅ All 3 required functions present with correct signatures
✅ activate/deactivate check msg.sender == maxExtractContract AND use tx.origin for tracking
✅ slash checks msg.sender == gameContract, verifies staked[killer], sets false, calls MaxExtract.slash()
✅ All required state variables present
✅ No reentrancy vulnerabilities or access control bypasses

=== FAIL CONDITIONS ===

❌ Missing any required function
❌ Wrong function signatures (wrong names, wrong parameters)
❌ activate/deactivate not checking msg.sender == maxExtractContract
❌ activate/deactivate using msg.sender instead of tx.origin for staking status
❌ slash not checking msg.sender == gameContract
❌ slash not verifying killer is staked
❌ slash not setting staked[killer] = false BEFORE external call
❌ slash not calling MaxExtract.slash(killer, sectorId)
❌ Missing required state variables
❌ Providing incorrect sectorId to MaxExtract.slash()
❌ Reentrancy vulnerability (setting staked[killer] = false AFTER external call)

=== NOTES ===

- Stake contract does NOT hold credits - MaxExtract holds all staked credits (10k per pilot)
- slash() MUST set staked[killer] = false BEFORE calling MaxExtract.slash() to prevent reentrancy and double-slashing
- sectorId can be obtained by reading from your Registry contract (e.g., registry.sectorId())
- The slash function must call MaxExtract.slash(killer, sectorId) with the correct function signature
